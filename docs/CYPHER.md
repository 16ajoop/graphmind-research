# Cypher queries

Generated by `python -m app.graph.export_cypher` from the query dicts in the backend. Do not edit by hand.

67 named, parameterised queries in four groups. The graph writes that build papers, authors, citations and results from a PDF are in `backend/app/graph/ingest.py`, next to the parsing code.

## Contents

- [Agent tools](#agent-tools) (34, `backend/app/graph/analysis.py` `Q`): The research agent's tools and the analysis views. Every fact in an answer comes from one of these; the LLM never writes Cypher.
- [Citation facts](#citation-facts) (6, `backend/app/agent/enrich.py` `FACT_Q`): What the graph can prove about why paper $a cites paper $b. The Extractor agent checks these before it falls back to cue words; each returns true or false.
- [Agent coordination and memory](#agent-coordination-and-memory) (16, `backend/app/agent/memory.py` `MEM_Q`): Jobs the four pipeline agents hand to each other, the lock in the graph, research sessions and insights.
- [UI views](#ui-views) (11, `backend/app/api/main.py` `VIEW_Q`): Read-only queries behind the web UI's paper panel, map, leaderboard pickers and sessions.

## Agent tools

### Two papers: every way they are connected

#### pair_citations

Parameters: `$a`, `$b`

```cypher
MATCH (a:Paper {id: $a})-[c:CITES]-(b:Paper {id: $b})
RETURN startNode(c).id AS citing, endNode(c).id AS cited, c.intent AS intent, c.contexts AS contexts
```

#### pair_shared_authors

### Results

#### leaderboard

One dataset/split/metric: every non-quoted result, with an erratum's value swapped in through (fix)-[:CORRECTS]->(r).

Parameters: `$dataset`, `$metric`, `$split`

```cypher
MATCH (d:Dataset {id: $dataset})<-[:ON_DATASET]-(r:Result)-[:MEASURED_BY]->(mt:Metric {id: $metric}),
      (r)-[:OF_METHOD]->(m:Method), (p:Paper)-[:REPORTS]->(r)
WHERE r.split = $split AND r.origin IN ['proposed', 'baseline_run', 'reproduced']
OPTIONAL MATCH (fix:Result)-[:CORRECTS]->(r)
RETURN m.name AS method, coalesce(fix.value, r.value) AS value, r.value AS as_published,
       fix IS NOT NULL AS corrected, r.origin AS origin, r.setting AS setting, p.id AS paper, p.published AS published,
       mt.higher_is_better AS higher_is_better
ORDER BY CASE WHEN mt.higher_is_better THEN -coalesce(fix.value, r.value) ELSE coalesce(fix.value, r.value) END
```

#### sota_check

A 'state of the art' claim is checked against every earlier, non-quoted result in its scope.

Parameters: none

```cypher
MATCH (p:Paper)-[:MAKES]->(c:Claim {type: 'sota'}), (p)-[:PROPOSES]->(m:Method)
UNWIND c.scope AS s
WITH p, c, m, split(s, '|') AS parts
MATCH (p)-[:REPORTS]->(own:Result)-[:OF_METHOD]->(m), (own)-[:ON_DATASET]->(d:Dataset {id: parts[0]}),
      (own)-[:MEASURED_BY]->(mt:Metric {id: parts[2]})
WHERE own.split = parts[1]
MATCH (op:Paper)-[:REPORTS]->(other:Result)-[:OF_METHOD]->(om:Method), (other)-[:ON_DATASET]->(d), (other)-[:MEASURED_BY]->(mt)
WHERE other.split = parts[1] AND om <> m AND op.published < p.published
  AND other.origin IN ['proposed', 'baseline_run', 'reproduced']
OPTIONAL MATCH (fix:Result)-[:CORRECTS]->(other)
WITH c, p, d, parts, own, om, op, coalesce(fix.value, other.value) AS value, mt
WHERE (mt.higher_is_better AND value > own.value) OR (NOT mt.higher_is_better AND value < own.value)
RETURN c.id AS claim, p.id AS paper, d.name AS dataset, parts[1] AS split, own.value AS claimed_value,
       om.name AS better_method, value AS better_value, op.id AS better_paper
ORDER BY better_value DESC
```

#### claim_pair_candidates

Pairs worth an LLM judgement: claims from different papers about the same method (newer -> older).

Parameters: none

```cypher
MATCH (p1:Paper)-[:MAKES]->(c1:Claim)-[:ABOUT]->(m:Method)<-[:ABOUT]-(c2:Claim)<-[:MAKES]-(p2:Paper)
WHERE p1.published > p2.published AND NOT (c1)-[:SUPPORTS|CONTRADICTS|QUALIFIES]->(c2)
WITH c1, c2, p1, p2, collect(DISTINCT m.name) AS shared_methods
OPTIONAL MATCH (c1)-[:ABOUT]->(d:Dataset)<-[:ABOUT]-(c2)
RETURN c1.id AS newer, c1.text AS newer_text, p1.title AS newer_paper,
       c2.id AS older, c2.text AS older_text, p2.title AS older_paper,
       shared_methods, collect(DISTINCT d.name) AS shared_datasets
```

#### unlinked_method_pairs

```cypher
WHERE m1.id < m2.id AND NOT (m1)-[:EXTENDS*1..5]-(m2) AND NOT (p1)-[:CITES]-(p2)
```

### Citation hygiene

#### missing_cit_candidates

Missing citations = earlier library papers this paper does not cite, scored by three signals. Each signal is its own query: on FalkorDB 6.0.1, chained OPTIONAL MATCH ... collect() stages lose rows, and a WHERE with a pattern predicate (NOT (p)-[:CITES]->(q)) must be followed by WITH before the next MATCH, or later variables come back "not defined".

Parameters: `$paper`

```cypher
MATCH (p:Paper {id: $paper}), (q:Paper {in_library: true})
WHERE q <> p AND q.published < p.published AND NOT (p)-[:CITES]->(q)
RETURN q.id AS paper, q.title AS title
```

#### missing_cit_shared_datasets

Parameters: `$paper`

```cypher
MATCH (p:Paper {id: $paper}), (q:Paper {in_library: true})
WHERE q <> p AND q.published < p.published AND NOT (p)-[:CITES]->(q)
WITH p, q
MATCH (p)-[:EVALUATES_ON]->(d:Dataset)<-[:EVALUATES_ON]-(q)
RETURN q.id AS paper, collect(DISTINCT d.name) AS items
```

#### missing_cit_similar_methods

Parameters: `$paper`

```cypher
MATCH (p:Paper {id: $paper}), (q:Paper {in_library: true})
WHERE q <> p AND q.published < p.published AND NOT (p)-[:CITES]->(q)
WITH p, q
MATCH (p)-[:PROPOSES]->(:Method)-[:SIMILAR_TO]-(sm:Method)<-[:PROPOSES]-(q)
RETURN q.id AS paper, collect(DISTINCT sm.name) AS items
```

#### missing_cit_stronger_results

Parameters: `$paper`

```cypher
MATCH (p:Paper {id: $paper}), (q:Paper {in_library: true})
WHERE q <> p AND q.published < p.published AND NOT (p)-[:CITES]->(q)
WITH p, q
MATCH (p)-[:PROPOSES]->(pm:Method)<-[:OF_METHOD]-(pr:Result)<-[:REPORTS]-(p)
MATCH (q)-[:PROPOSES]->(qm:Method)<-[:OF_METHOD]-(qr:Result)<-[:REPORTS]-(q)
WHERE qr.split = pr.split AND qr.value > pr.value
MATCH (pr)-[:ON_DATASET]->(d:Dataset)<-[:ON_DATASET]-(qr)
MATCH (pr)-[:MEASURED_BY]->(:Metric {higher_is_better: true})<-[:MEASURED_BY]-(qr)
RETURN q.id AS paper, collect(DISTINCT qm.name + ' > ' + pm.name + ' on ' + d.name + ' ' + qr.split) AS items
```

### People and influence (FalkorDB algorithms)

#### influential_papers

PageRank over CITES: a paper ranks high when papers that are themselves well cited cite it.

Parameters: `$k`

```cypher
CALL algo.pageRank('Paper', 'CITES') YIELD node, score
RETURN node.id AS id, node.title AS title, node.in_library AS in_library, score ORDER BY score DESC LIMIT $k
```

#### bridge_authors

Betweenness over COAUTHOR (stored both ways). FalkorDB samples betweenness, so the seed is fixed for repeatable rankings.

Parameters: `$k`

```cypher
CALL algo.betweenness({nodeLabels: ['Author'], relationshipTypes: ['COAUTHOR'], samplingSize: 1000, samplingSeed: 7})
YIELD node, score
RETURN node.name AS author, score ORDER BY score DESC LIMIT $k
```

#### author_groups

Weakly connected components over COAUTHOR: groups of authors with no co-author path between them.

### ranks_their_method

their method has a result next to another method's result on the same dataset, split and metric: a comparison

Parameters: `$a`, `$b`

```cypher
MATCH (a:Paper {id: $a})-[:REPORTS]->(r:Result)-[:OF_METHOD]->(m:Method)

                             RETURN count(*) > 0
```

## Agent coordination and memory

From `backend/app/agent/memory.py` (`MEM_Q`). Jobs the four pipeline agents hand to each other, the lock in the graph, research sessions and insights.

### Jobs: one per uploaded PDF, moved through the stages by different agents

#### job_create

Parameters: `$file`, `$id`

```cypher
MERGE (j:Job {id: $id}) SET j.stage = 'parse', j.status = 'ready', j.file = $file,
      j.created_at = timestamp(), j.attempts = 0, j.history = [], j.error = NULL
```

#### job_claim

One write query = one atomic step: FalkorDB runs write queries one at a time per graph, so two agents can never claim the same job. A stage waits until no job is still in an earlier stage (ready or running): citation intents and claim pairs depend on which papers exist, so each stage runs as a wave over the whole upload.

Parameters: `$agent`, `$earlier`, `$stage`

```cypher
OPTIONAL MATCH (k:Job) WHERE k.stage IN $earlier AND k.status IN ['ready', 'running']
WITH count(k) AS blocking
MATCH (j:Job {stage: $stage, status: 'ready'}) WHERE blocking = 0
WITH j ORDER BY j.created_at LIMIT 1
SET j.status = 'running', j.claimed_by = $agent, j.claimed_at = timestamp(), j.attempts = j.attempts + 1
RETURN j.id AS id, j.file AS file
```

#### job_link_paper

Parameters: `$id`, `$paper`

```cypher
MATCH (j:Job {id: $id}), (p:Paper {id: $paper}) MERGE (j)-[:FOR_PAPER]->(p) SET j.paper = $paper
```

#### job_advance

Parameters: `$agent`, `$id`, `$next`

```cypher
MATCH (j:Job {id: $id})
SET j.history = j.history + [$agent + ':' + j.stage], j.stage = $next, j.attempts = 0,
    j.status = CASE WHEN $next = 'done' THEN 'done' ELSE 'ready' END, j.claimed_by = NULL
```

#### job_fail

Parameters: `$error`, `$id`, `$max_attempts`

```cypher
MATCH (j:Job {id: $id})
SET j.error = $error, j.claimed_by = NULL,
    j.status = CASE WHEN j.attempts >= $max_attempts THEN 'failed' ELSE 'ready' END
```

#### job_requeue_stale

A job left 'running' by a crashed process goes back to 'ready' after $older_ms.

Parameters: `$older_ms`

```cypher
MATCH (j:Job {status: 'running'}) WHERE j.claimed_at < timestamp() - $older_ms
SET j.status = 'ready', j.claimed_by = NULL RETURN count(j) AS requeued
```

#### job_board

Parameters: none

```cypher
MATCH (j:Job) OPTIONAL MATCH (j)-[:FOR_PAPER]->(p:Paper)
RETURN j.id AS id, j.file AS file, p.title AS title, j.stage AS stage, j.status AS status,
       j.claimed_by AS agent, j.attempts AS attempts, j.history AS history, j.error AS error,
       j.created_at AS created_at
ORDER BY created_at
```

### A mutex in the graph, for steps that change the whole graph (ingest, reconcile, intent labels).

#### lock_acquire

Same trick as job_claim: one atomic write query. A holder older than $stale_ms is presumed crashed.

Parameters: `$agent`, `$name`, `$stale_ms`

```cypher
MERGE (l:Lock {name: $name})
WITH l WHERE l.holder IS NULL OR l.holder = $agent OR l.acquired_at < timestamp() - $stale_ms
SET l.holder = $agent, l.acquired_at = timestamp()
RETURN l.holder AS holder
```

#### lock_release

Parameters: `$agent`, `$name`

```cypher
MATCH (l:Lock {name: $name}) WHERE l.holder = $agent SET l.holder = NULL
```

### Research sessions (episodic memory) and insights (what the user decided to keep)

#### session_start

```cypher
MERGE (s:ResearchSession {id: $id}) ON CREATE SET s.started_at = timestamp(), s.title = $title

```

#### question_log

The full answer is stored on the Question node as JSON text: no second database (CLAUDE.md rule 8).

Parameters: `$about`, `$answer`, `$id`, `$intent`, `$session`, `$text`

```cypher
MATCH (s:ResearchSession {id: $session})
CREATE (q:Question {id: $id, text: $text, intent: $intent, asked_at: timestamp(), answer: $answer})
CREATE (s)-[:ASKED]->(q)
WITH q UNWIND $about AS aid MATCH (x {id: aid}) MERGE (q)-[:ABOUT]->(x)
```

#### insight_save

Parameters: `$about`, `$id`, `$session`, `$text`

```cypher
MATCH (s:ResearchSession {id: $session})
CREATE (i:Insight {id: $id, text: $text, saved_at: timestamp()})
CREATE (s)-[:SAVED]->(i)
WITH i UNWIND $about AS aid MATCH (x {id: aid}) MERGE (i)-[:ABOUT]->(x)
```

#### reading_list_add

Parameters: `$paper`, `$reason`, `$session`

```cypher
MATCH (s:ResearchSession {id: $session}), (p:Paper {id: $paper}) MERGE (s)-[r:READING_LIST]->(p)
SET r.added_at = timestamp(), r.reason = $reason
```

#### recall_insights

Insights about any of $ids; with no ids (e.g. "What did I save earlier?") every saved insight.

Parameters: `$ids`

```cypher
MATCH (s:ResearchSession)-[:SAVED]->(i:Insight)
OPTIONAL MATCH (i)-[:ABOUT]->(x)
WITH s, i, collect(DISTINCT x.id) AS about
WHERE size($ids) = 0 OR any(a IN about WHERE a IN $ids)
RETURN i.text AS insight, about, s.title AS session, i.saved_at AS saved_at
ORDER BY saved_at DESC
```

#### session_history

Parameters: `$session`

```cypher
MATCH (s:ResearchSession {id: $session})-[:ASKED]->(q:Question)
RETURN q.id AS id, q.text AS question, q.intent AS intent, q.asked_at AS asked_at, q.answer AS answer
ORDER BY asked_at
```

#### whats_new_since

Papers added after the session last asked about a topic, connected to that topic.

Parameters: `$session`

```cypher
MATCH (s:ResearchSession {id: $session})-[:ASKED]->(q:Question)-[:ABOUT]->(x)
MATCH (p:Paper {in_library: true})-[r]->(x)
WHERE p.added_at > q.asked_at
RETURN DISTINCT p.id AS paper_id, p.title AS paper, type(r) AS relation, x.id AS topic, q.text AS earlier_question
```

```cypher
MATCH (p:Paper {id: $id})-[:MAKES]->(c:Claim)
OPTIONAL MATCH (c)-[:ABOUT]->(x)
RETURN c.id AS id, c.text AS text, c.type AS type, collect(x.name) AS about
```

### paper_results

Parameters: `$id`

```cypher
MATCH (p:Paper {id: $id})-[:REPORTS]->(r:Result)-[:OF_METHOD]->(m:Method), (r)-[:ON_DATASET]->(d:Dataset),
      (r)-[:MEASURED_BY]->(mt:Metric)
RETURN m.name AS method, d.name AS dataset, r.split AS split, mt.name AS metric, r.value AS value,
       r.origin AS origin, r.setting AS setting
ORDER BY dataset, split, method
```

### sessions

Parameters: none

```cypher
MATCH (s:ResearchSession)
OPTIONAL MATCH (s)-[:ASKED]->(q:Question)
RETURN s.id AS id, s.title AS title, s.started_at AS started_at, count(q) AS questions
ORDER BY started_at DESC
```
